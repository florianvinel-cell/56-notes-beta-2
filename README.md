# 56 notes — bêta 2.0

Une note par soir, pendant huit semaines. On raconte sa journée, on la traduit en une note de musique, et peu à peu un ciel se dessine : une constellation par semaine, une mélodie qui n'appartient qu'à soi.

**Ouvrir l'app :** https://florianvinel-cell.github.io/56-notes-beta-2/

Cette seconde version d'essai présente un ciel fictif déjà avancé : 32 notes et neuf pensées permettent de découvrir immédiatement la constellation, les mélodies hebdomadaires et le carnet.

Tout ce que tu ajoutes (ta mélodie-clé, tes nouveaux soirs, tes pensées) reste sur ton appareil, dans ton navigateur : rien n'est envoyé nulle part. Son stockage est isolé de la première bêta. Si tu changes d'appareil ou effaces les données de ton navigateur, tes ajouts personnels repartent de zéro ; le récit de démonstration reste inclus dans l'app.
